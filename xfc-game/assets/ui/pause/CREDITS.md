# Pausa — referência fornecida pelo usuário

Fonte: `file_0000000082f8820ebe361acb35688e2b.png`, imagem enviada na conversa.
Recortes da marca XFC 27, das cinco linhas do menu e do rodapé A/B. Fundo escuro
removido dos glifos; nenhum trecho do campo é usado como fundo da partida.

A interface continua sendo botões DOM com rótulos acessíveis e ações reais. O
campo atrás é a partida real congelada. Recortes preservam o desenho fornecido,
não uma nova geração ou redesenho dos ícones/tipografia. Script de extração:
`tools/extract-pause-reference.py` (Pillow; normalização para palco 1280×720).
Os PNGs desta revisão foram normalizados com ImageMagick antes da extração;
Pillow pode produzir diferenças mínimas de antialiasing ao regenerar.
