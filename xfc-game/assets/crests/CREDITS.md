# Créditos dos escudos

Os escudos são marcas dos clubes e estão no pacote apenas para o protótipo do
menu do XFC — pertencem aos respectivos clubes.

| Clube | Escudo | Origem |
| --- | --- | --- |
| FC Barcelona | `fc-barcelona.png` | marca oficial do clube (uso apenas ilustrativo) |
| Real Madrid | `real-madrid.png` | marca oficial do clube (uso apenas ilustrativo) |
| Ibis Esporte | `ibis-esporte.png` | https://vectorportal.com/pt/vector/logotipo-do-vetor-do-clube-de-esporte-de-ibis/1498 |
| Paraná Clube | `parana-clube.png` | https://logodownload.org/parana-clube-logo-escudo/ |

As blusas dos clubes **não são imagens**: são desenhadas em SVG pelo próprio
jogo (`xfc-game/src/data/kits.js`), a partir das cores dos escudos.
