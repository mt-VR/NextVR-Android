# XFC 27 — v0.5.58: escudos reais, seleções por letra, campo grandão

versionCode 64. TAG `xfc-gameplay-v0.5.58`.

## Escudos reais das seleções

O HTML `XFC27_Escudos_Selecoes_Mundo.html` aponta para a galeria FootyLogos /
football-logos.cc (210 seleções, PNG+SVG). Na v0.5.57 os brasões tinham sido
*gerados* (iniciais + cores da camisa). Isso saiu.

Agora `assets/crests/nations/<flag>.png` são os **escudos oficiais** das
federações, rasterizados a 256 px a partir dos SVG da mesma coleção.
Kick Off, HUD e tela de resultado passam a mostrar CBF, AFA, FFF, etc.

## Seleções por letra

No Kick Off o seletor de seleções **não** lista confederação (América, Ásia,
UEFA…). Lista **A–Z**. Brasil fica em B, Argentina em A, França em F.
As setas ‹ › percorrem só as seleções daquela letra.

## Campo maior

Gramado 120×82 → **140×96 m**. Câmera recua (z 45→56, altura 16→20) para o
estádio parecer grandão, como os reais.
