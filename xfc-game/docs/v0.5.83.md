# XFC 27 — v0.5.83: passe carregado, enfiada interceptável, lateral do jogador

versionCode 89. TAG `xfc-gameplay-v0.5.83`.

- PASS: toque = passe fraco; segura = passe forte; segura e arrasta pra cima = passe alto.
- THROUGH: barra de força; a bola vai reta no espaço.
- Rivais correm, interceptam, dão carrinho ou chutam pra longe.
- Lateral: o jogador cobra com PASSE; a IA só cobra o lado dela.
