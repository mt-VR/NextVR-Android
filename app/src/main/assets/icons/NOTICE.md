# Brand icons — provenance

These are existing brand marks, not generated substitute illustrations. Logos and names belong to their respective owners; inclusion does not imply endorsement.

- Google, YouTube, Reddit, GitHub, Twitch, Maps: SVG Logos collection by Gil Barbara, distributed via `@iconify-json/logos@1.2.18` (CC0 collection metadata). https://github.com/gilbarbara/logos — original SVG paths retained in `sources/`. Brand trademark rights are separate from the collection license.
- Wikipedia globe: Wikimedia's portal repository, `src/wikipedia.org/assets/img/Wikipedia-logo-v2@2x.png`, commit `ffcfbe2f0513112f4a448181c35f1d3051b3da82`. https://github.com/wikimedia/portals . Wikimedia logo/trademark rights remain with Wikimedia Foundation.
- Poki: existing Poki icon from Construct SDK integration `skymen/poki_sdkV2`, `src/icon.svg`, commit `31264314c1e587b993870dfd126642e4934135e2`. https://github.com/skymen/poki_sdkV2 . Poki trademark rights remain with Poki.

PNG files are transparent 256px letterboxed rasterizations of these source assets, bundled locally for the WebView library and Android browser header. `manifest.json` records output SHA-256 digests. No remote favicon requests are made at runtime.

`dixvr-app.png`: ícone DI fornecido pelo usuário no arquivo `4466dc671e9a743166bafd9b31ed85b6.jpg`, convertido para PNG sem redesenhar. Usado também nos recursos do launcher Android; não pertence à coleção de logotipos dos serviços acima.
